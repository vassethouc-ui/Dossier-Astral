# 🚀 Démarrage rapide (aucune compétence technique requise)

## Pour simplement voir/utiliser le site

Tu n'as besoin **d'aucun logiciel spécial**, pas d'IDE, pas de programme à installer.

1. Dans le dossier que tu as téléchargé, trouve le fichier **`solaire.html`**
2. **Double-clique dessus** — il va s'ouvrir automatiquement dans ton navigateur habituel (Chrome, Firefox, Edge, Safari...)
3. C'est tout ! Le système solaire est fonctionnel, comme dans les captures d'écran.

## Pour le mettre en ligne (avoir un vrai lien à partager)

Si tu veux que d'autres personnes puissent y accéder via un lien internet (pas juste sur ton ordinateur), voici l'option la plus simple, **sans écrire une seule ligne de code** :

1. Va sur [netlify.com](https://www.netlify.com) et crée un compte gratuit
2. Une fois connecté, cherche l'option **"Deploy manually"** ou glisse-dépose directement le dossier complet du projet sur la page d'accueil
3. Netlify te donne un lien en quelques secondes (ex. `tonprojet.netlify.app`)
4. Partage ce lien avec qui tu veux

## Pour utiliser ton propre nom de domaine (ex. tonnom.com)

Si tu préfères un lien personnalisé plutôt que `tonprojet.netlify.app`, voici les étapes :

1. **Achète un nom de domaine** sur un site comme [namecheap.com](https://www.namecheap.com) ou [porkbun.com](https://porkbun.com) — compte entre 8 000 et 20 000 GNF par an selon l'extension choisie (`.com`, `.io`, etc.)
2. Une fois ton site en ligne sur Netlify (étape précédente), va dans les paramètres de ton site Netlify → **"Domain settings"** → **"Add a custom domain"**
3. Netlify t'indique 2-3 informations techniques (des "DNS") à copier-coller dans les paramètres de ton nom de domaine, chez Namecheap/Porkbun — chaque site a un guide détaillé pour cette étape précise, cherche "connecter mon domaine à Netlify" dans leur aide
4. Le changement peut prendre de quelques minutes à 24h pour s'activer partout

C'est la seule étape qui demande un peu plus de patience, mais aucune ligne de code n'est nécessaire — que du copier-coller entre deux sites.

## Pour changer une couleur, un texte, etc. (personnalisation simple)

Si tu veux modifier quelque chose toi-même (voir `CUSTOMISATION.md` pour le détail), tu as besoin d'un simple **éditeur de texte** — pas d'un IDE compliqué :

- **Notepad++** (Windows, gratuit) — [notepad-plus-plus.org](https://notepad-plus-plus.org)
- **Visual Studio Code** (Windows/Mac, gratuit, un peu plus complet) — [code.visualstudio.com](https://code.visualstudio.com)

Ouvre le fichier à modifier avec l'un de ces programmes (clic droit → "Ouvrir avec"), fais ton changement, enregistre (Ctrl+S), et recharge la page dans ton navigateur pour voir le résultat.

## Besoin d'aide ?

Si tu bloques sur une étape, n'importe qui avec des bases en informatique (même sans être développeur) peut généralement t'aider à suivre ce guide en quelques minutes.
